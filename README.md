# Glyph Gestures by Moorle: feedback

Public place to ask questions, suggest features and report bugs for Glyph Gestures, the Unity gesture
recognition package. This repository holds no code.

## What goes where

| I want to... | Go here |
|---|---|
| Suggest a feature or vote on one | [Discussions, Ideas](https://github.com/moorle-dev/glyph-gestures-feedback/discussions/categories/ideas) |
| Ask how something works | [Discussions, Q&A](https://github.com/moorle-dev/glyph-gestures-feedback/discussions/categories/q-a) |
| Report something broken | [New bug report](https://github.com/moorle-dev/glyph-gestures-feedback/issues/new?template=bug-report.yml) |
| See what is planned and what shipped | [Roadmap](https://github.com/orgs/moorle-dev/projects) and [Releases](https://github.com/moorle-dev/glyph-gestures-feedback/releases) |
| Ask about your invoice, licence or anything private | Email {{SUPPORT_EMAIL}} |

Vote on an idea by clicking its upvote. The most upvoted ideas are read first. You need a GitHub
account to vote; without one, email your idea and it will be filed for you.

## What support covers

- Questions about using Glyph Gestures.
- Bugs in the package.

Please send your package version and Unity version, and your invoice number when you email.
Custom feature work for a single project is not covered.

## Not planned

Ideas on this list will not be built. Asking again is fine, but the answer is likely the same.

## Roadmap
