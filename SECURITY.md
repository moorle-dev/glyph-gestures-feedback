# Security

If you found a security problem in Glyph Gestures, please do not open a public issue.

Email hello@moorle.dev with the subject "[Glyph] Security", the package version, the Unity version
and the steps to reproduce. I read every report and answer it privately; my reply comes from
moorle.dev@gmail.com. Please give a reasonable time to fix the problem before you share it publicly.

This repository holds no code, so only the Glyph Gestures package itself is in scope.
