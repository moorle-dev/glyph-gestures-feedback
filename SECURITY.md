# Security

If you found a security problem in Glyph Gestures, please do not open a public issue.

Email moorle.dev@gmail.com with the subject "[Glyph] Security", the package version, the Unity version
and the steps to reproduce. You will get an answer within a week. Please give a reasonable time to
fix the problem before you share it publicly.

This repository holds no code, so only the Glyph Gestures package itself is in scope.
